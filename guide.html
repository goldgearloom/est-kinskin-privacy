EST キンスキン 使い方とご注意

はじめにお読みください

  1. この拡張機能は kintone の公式機能ではありません。サイボウズ株式会社とは関係ありません。
  2. kintone の更新で、一部の見た目が反映されなくなることがあります。
  3. 適用すると、そのアプリを使うすべてのユーザー（ゲストを含む）に表示されます。
  4. 適用は kintone の管理者だけが行えます。
  5. 不具合があれば「外す」で、この拡張機能のファイルをアプリから外して元の見た目に戻せますが、反映に少し時間がかかることがあります。
  6. 業務で使う前に、テストアプリで確認することをおすすめします。
  7. ライトコースでは利用できません。

できること

サイドパネルの上のタブで、3 つに分かれています。タブごとにファイルが 1 つあり、タブの最初の欄に、ファイルの名前と、開いているアプリに登録されているか（緑＝登録されています、灰＝登録されていません）が出ます。その下のボタンで、そのファイルだけを適用・外す・ファイルに保存・コピーできます。「ファイルに保存」と「コピー」は、いまのサイドパネルの設定から作った内容です（アプリに登録されているファイルではありません）。いちばん上のプレビューは、3 つを合わせた見た目を確かめます。

タブ中身ファイル
スキンスキン、配色、形と大きさ。どのアプリにも同じ値を使えます。est-kinskin.css
カスタム要素カスタマイズで追加したボタンなど。設定はアプリごとに保存します。est-kinskin-custom.css
フィールドフィールドの色。レコードの詳細・編集・追加の画面でだけ使えます。設定はアプリごとに保存します。est-kinskin-fields.js
  • スキンを選ぶ: ライト、ダーク、ビジネス、やわらかの 4 種類から選びます。「ダーク」は見出しとボタンを濃い色にする見た目で、画面全体は暗くなりません。
  • 配色を調整する: メイン色と文字色を選びます。kintone のデザインテーマ（アプリの設定 >「一般設定」）の上に重ねて表示されます。デザインテーマは kintone で選んでください。
  • 形と大きさを調整する: 角丸、ボタンの形と高さ、文字の大きさを変えます。
  • フィールドの色: 強調したいフィールドに、フィールド全体・内容・フィールド名の色や太さを付けます（kintone 公式の機能を使います）。フィールドは、レコードの詳細の画面で「画面で選ぶ」を押し、kintone の画面でクリックして追加します（続けて選べます。終わるときは Esc か「選ぶのをやめる」）。各行の見出しには設定の見本（「名」がフィールド名、「値」が内容の見た目）が出て、押すと開いたり閉じたりします。右のアイコンは、左から「設定をコピー」「貼り付け」（ほかのフィールドを同じ設定にする）、「外す」です。
  • カスタマイズの要素: カスタマイズで追加したボタンなど（ID を付けた要素）の、色、枠、角丸、余白、文字の大きさ、マウスを乗せたときの色を整えます。「画面で選ぶ」で選びます。フィールドと同じく、続けて選べ、Esc か「選ぶのをやめる」で終わります。選べるのは、カスタマイズ用の空白部分の中の ID のある要素だけです（ID のない要素にマウスを乗せると、ID のある親が選ばれます）。行の折りたたみ、見本、コピー・貼り付け・外すのアイコンもフィールドと同じです。上級者向けに、CSS を直接書くこともできます。
  • プレビュー: 開いている画面だけに、保存せずに一時的に反映します。
  • 適用・外す: そのタブのファイルを、アプリのカスタマイズ（PC 用）に登録して反映します。「外す」で、そのファイルをアプリから外せます。適用するのは開いているアプリだけで、システム全体（すべてのアプリ）には使いません。
  • 保存: タブごとのファイルを、自分の PC に保存します。管理者でなくても使えます。

使い方

  1. kintone のアプリ（一覧、またはレコードの画面）を開きます。
  2. ツールバーの EST キンスキンのボタンを押して、サイドパネルを開きます。初めてのときは注意を読んで同意します。
  3. 「スキン」のタブでスキンを選び、配色、形と大きさを調整します。必要なら「カスタム要素」のタブでボタンなどを、「フィールド」のタブ（レコードの画面で）でフィールドの色を決めます。
  4. サイドパネルのいちばん上のスイッチ「この画面でプレビュー」をオンにして、見た目を確かめます（パネルを開いたときはオフです）。一覧とレコードの画面の両方で確かめることをおすすめします。
  5. プレビューがオンのまま、そのタブの「適用」を押し、確認の画面で内容を確かめて「理解しました」にチェックを入れ、「適用する」を押します（「適用」はプレビューがオンのときだけ押せます）。
  6. 反映が終わったら、kintone の画面を再読み込みして確かめます。

適用の確認の画面に出るもの

  • 今の適用の範囲（「すべてのユーザー」でないときは、一般のユーザーには表示されません。範囲はこの拡張機能では変えません）
  • まだ反映していないアプリの設定の変更があるときの注意（一緒に反映されます）
  • 加えるファイル、外すファイル（前にこの拡張機能で適用したもの）、残すファイルの数
  • 変わる値の前と後

外す

そのタブの「外す」を押すと、そのタブのファイルをアプリの設定から外して（なくして）反映します。前の内容に戻すのではありません。ほかのタブのファイルや、ほかのファイルはそのまま残ります。アプリの一般設定（デザインテーマなど）は変えません。

反映には数秒かかります。その間、同じアプリの設定を変えるとエラーになることがあります。

うまく反映されないとき

  • プレビューを始めると、見た目を変える対象が画面にあるかを確かめます。見つからないものがあると、サイドパネルに警告が出ます。kintone の更新で画面の作りが変わった可能性があります。適用したあとに崩れたときは、そのタブの「外す」でファイルを外してください。
  • 一覧で文字を 16px 以上にすると、列の幅が足りずに「…」で切れることがあります。
  • 日付の入力欄とボタンの文字の大きさは変わりません。
  • カスタム要素のタブで選べるのは、kintone の「カスタマイズ用の空白部分」（一覧のメニューの右と下、レコードのメニューの上、スペースのフィールド）の中の、ID のある要素だけです。kintone の歯車や鉛筆などのボタンは選べません。空白部分の外に置いた要素は「自由な CSS」で書いてください。
  • カスタマイズの要素は、ID を付けた要素がいちばん安定して指定できます。kintone の標準のクラスで指定したものは、kintone の更新で効かなくなることがあります。
  • 自由な CSS では、@import と外部の url() は使えません（すべてのユーザーの画面で外部を読み込ませないため）。
  • スマートフォン用の画面と、PC の旧デザインには、まだ対応していません。

情報の取り扱い

  • この拡張機能は、開発者のサーバーを使いません。kintone 以外の外部には何も送りません。
  • kintone に対しては、ログイン中のあなたの権限で、アプリの設定の読み取りと、適用・外すときの設定の変更だけを行います。レコードのデータは読みません。
  • パスワードや API トークンは使わず、保存もしません。
  • スキンの値、同意の記録、適用の記録は、このブラウザーの中（chrome.storage）だけに保存します。

「kintone」はサイボウズ株式会社の登録商標です。この拡張機能は、サイボウズ株式会社とは関係のない個人が開発したものです。
