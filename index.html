プライバシーポリシー

Chrome 拡張機能「EST キンスキン」（以下「本拡張機能」）の、情報の取り扱いについて説明します。

制定日：2026年10月16日（同日、カスタマイズの要素の項目を追加）／改定日：2026年10月21日（「元に戻す」を「外す」に、要素の選び方を「画面で選ぶ」だけに）／改定日：2026年10月22日（「外す」を「削除」に。登録したファイルの内容をパネルに読み込むことを追記）

1. 開発者のサーバーについて

本拡張機能は、開発者が運営するサーバーを使いません。利用者の kintone の情報を、開発者が受け取ることはありません。アクセス解析や広告のためのデータ収集も行いません。

2. 外部に送る情報

kintone 以外の外部には、何も送りません。AI などの外部サービスとも連携しません。

3. kintone で読み取る情報と、変更する設定

本拡張機能は、利用者がログインしている kintone の画面で、利用者の権限のまま動きます。パスワードや API トークンは使わず、保存もしません。

読み取る情報使う目的
画面のデザインのバージョン、アプリ ID、画面の種類（URL から判断）対応している画面かを判断するため
見た目を変える対象（画面の要素）があるかどうかkintone の更新で見た目が反映されない可能性を知らせるため。結果はサイドパネルに出すだけです
カスタマイズの空白部分にある要素の ID、クラス、種類、表示されている文字（40 文字まで）。利用者が「画面で選ぶ」でクリックしたときだけ見た目を整える要素を選べるようにするため。結果はサイドパネルに出すだけです
アプリのフィールドの一覧（フィールドコード、フィールド名、種類）フィールドの色を付けるフィールドを選べるようにするため
アプリの JavaScript / CSS カスタマイズの設定（ファイル名、適用の範囲、版の番号）「適用」「削除」で、確認の画面を出し、ほかのファイルを残したまま設定を変えるため
前に本拡張機能で適用したファイル（CSS と JavaScript）の内容確認の画面で、変わる値の前と後を表示するため。カスタム要素とフィールドの色の設定を、パネルに読み込むため

レコードのデータは読み取りません。

利用者が確認の画面で「適用する」または「削除する」を押したときだけ、そのアプリの PC 用のカスタマイズ設定（本拡張機能のファイル est-kinskin.css、est-kinskin-custom.css、est-kinskin-fields.js の追加と削除。どれを変えるかは利用者が選んだタブによります）を変更し、反映します。ほかのファイル、適用の範囲、モバイル用の設定、アプリの一般設定（デザインテーマなど）は変えません。

4. この端末に保存する情報

保存する情報保存する場所
注意への同意の記録（日時）このブラウザーの拡張機能の保存領域（chrome.storage.local）
アプリごとの適用の記録（日時、ファイル名、スキンの値、色を付けたフィールドのフィールドコード）同上
アプリごとのカスタマイズの要素の設定（対象の指定、見た目の値、利用者が書いた CSS）このブラウザーの拡張機能の保存領域（chrome.storage.local）
アプリごとのフィールドの色の設定（フィールドコードと色）このブラウザーの拡張機能の保存領域（chrome.storage.local）
作業中のスキンの値、選んでいたタブブラウザーを閉じると消える領域（chrome.storage.session）

本拡張機能を削除すると、これらの情報も削除されます。
